# R0 Direct Locate

**Retrieval stage:** R0

**Goal:** resolve a claim from a known or narrowly identifiable target

**Immediate child:** [`discovery.md`](discovery.md)

Read the known file/symbol, exact identifier, route, configuration key, or error location and the minimum context that makes it meaningful. Use one narrow literal search when needed. Follow a directly referenced definition only if it resolves the same bounded claim.

Return source locations and the supported conclusion when sufficient. If location is unknown **or the located target leaves a material evidence gap**, load R1 Ranked Discovery. Carry known paths forward; finding a file is not the same as proving the answer. Do not jump to a later stage or broaden into a repository tour.
