# Experiments

Create one record before validating a Skill change.

```markdown
# EXP-<id> — <title>

## Evidence / pattern
What observed mechanism motivates this?

## Hypothesis
What should improve and why?

## Change
Exact boundary, level, or rule change.

## Expected result
Correctness/safety/build constraints first; then over/under-escalation and cost.

## Frozen validation
Candidate commit, task manifest, model/harness, runs, baseline.

## Result
Observed quality and cost metrics.

## Decision
accept | reject | inconclusive

## Follow-up
What new evidence would justify revisiting?
```

Do not rewrite the hypothesis after seeing partial results.
