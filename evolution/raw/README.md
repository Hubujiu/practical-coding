# Raw evolution evidence

This is the immutable evidence layer for maintenance-time skill evolution.

- `sessions/` contains sanitized receipts distilled from explicitly requested real-project/session experience.
- Benchmark execution traces remain under their benchmark result artifacts and should be referenced rather than copied here.
- Never store secrets, private code, personal identifiers, full chat transcripts, or private chain-of-thought.
- Once a receipt is used for an evolution decision, do not rewrite it to match the later conclusion. Add a new receipt when evidence changes.
